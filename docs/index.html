How to read these numbers

  • The model price is an estimate of a transfer fee, not a quality rating. On real transfers it had never seen (2024–2026), this version was off by a median of about 42%.
  • The model range is an 80% interval: for four in five real transfers, the actual fee fell inside it.
  • Each yearly price uses only transfers that happened before that date.
  • The model learns from players who were actually sold, and it knows nothing about contract length, so prices for players who are not for sale are less reliable.
  • Data: Transfermarkt, via the open transfermarkt-datasets project. Last update 6 July 2026.
